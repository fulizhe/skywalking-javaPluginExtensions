进程内 mock-OAP gRPC server,按 SkyWalking 原生 agent 协议(默认 11800)接收 go / node / java 等各语言 agent 的上报。下面每个面板对应一个读接口,参数都在页面上直接操作, 不需要再敲 curl。点链路清单里的 traceId 看链路图。打开 JVM Metrics 监控大盘 →

采集状态 GET /mock-oap/status

触发方式 GET /demo/chain | /demo/slow | /demo/error

按钮让本进程自己调自己:agent 为 HTTP 出口生成 Exit span,并把链路上下文传给下一跳, 于是得到一条多段链路。前提:本进程用 -javaagent 挂载了原生 SkyWalking agent (见 demo/README.md),且 agent 上报到本进程内的 collector(默认 127.0.0.1:11800)。 不需要 go / node 等外部服务。

— 每个 step 一次 /demo/leaf 调用
