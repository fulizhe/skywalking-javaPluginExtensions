mock-OAP 演示导航

本进程同时是业务应用和 mock-OAP 接收端。下面的按钮会制造演示流量, 页面入口按用途分组 —— 也可以从页面顶部互相跳转。

读取采集状态…

第一步:生成演示流量

第一条是 Java → Go → C++ → Node 的跨语言链路(需要 emitters 起着);生成后打开「采集总览」,点链路清单里的 traceId 看时序图。

第二步:打开页面

总览

采集可观测

采集状态、链路清单、最近日志。点 traceId 进入链路图。

 日志

日志检索

按 traceId、级别、关键字查日志,支持跳到对应链路。

 指标

JVM 指标

Agent 上报的堆内存、GC、线程等曲线。

 链路

链路时序图

单条 trace 的时序 / 树 / 表格视图,从总览里的 traceId 进入。

数据保存在本进程内存中,重启即清空。接口清单见 采集总览 各面板标题, 接入方式见 demo/README.md 与 ../docs/usage.md。
