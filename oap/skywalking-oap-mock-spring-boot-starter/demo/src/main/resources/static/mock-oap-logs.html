mock-OAP 接收到的日志

本进程内嵌的 mock-OAP 实现了 SkyWalking 原生 LogReportService, 所以应用 logback.xml 里那个 GRPCLogClientAppender 不再报 UNIMPLEMENTED, 日志被收进本地环形缓冲。采集器自身的日志会被拒收,避免「收日志 → 打日志 → 再被采集」无限放大。

级别说明:SkyWalking 的 LogData 没有 level 字段,这里的级别优先取 tags 里的 level,否则从正文里找独立成词的级别关键字;都取不到就显示「未分级」。
