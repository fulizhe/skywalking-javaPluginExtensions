# 04 — 依赖拓扑页：总览档 / 明细档 + 双向跳转

**What to build:** 新增**独立**拓扑页，两档视图切换，与既有页面双向跳转。沿用现有仪表盘目录结构与 ECharts 力导向图样式，**零新依赖**（组件库已在本地，无 CDN）。

**Blocked by:** 03（数据来自新读口）、01（明细档标签口径来自实跑结论）。

**Status:** ready-for-agent

### 页面

- [ ] 独立新页（不并入既有链路可视化页、不并入指标页）。理由：既有链路可视化页当前是把 span 按开始时间串成一条链，未用父子关系，与依赖拓扑的数据模型、刷新周期、点击语义都不同。
- [ ] **两档视图**：
  - [ ] **总览档** —— 右列只显示组件类型；节点少而稳定、布局稳定，可直接截图进汇报材料。
  - [ ] **明细档** —— 右列显示组件类型 + 出口操作名；标签文案按 issue 01 的实跑结论定。
- [ ] 左列入口端点**取自现有 Trace 指标读口**（含端点级分位与最差分钟分位），本票不为左列新增任何后端代码。
- [ ] **健康表达**：节点按依赖边错误率**四档着色**（绿/黄/橙/红，阈值为硬编码常量，**不照抄 OAP 的 100/99.9/99/95**）；最近有错误调用的依赖节点加**醒目标记**。图例写清各档阈值。
- [ ] **时间窗**：沿用读口的时间桶参数；页面提供「近 5 分钟 / 近 1 小时 / 自定义」快捷选择，**默认近 5 分钟并显示绝对时间范围**（便于截图与说明对齐）。
- [ ] 页面沿用现有仪表盘的取数/渲染风格与轮询节奏。

### 跳转

- [ ] **点入口端点** → 既有慢查询页 / 链路可视化。
- [ ] **点依赖边 / 依赖节点** → 该依赖上的慢链路（既有慢查询能力 + 依赖过滤）。
- [ ] 入口登记到仪表盘导航页。

### 口径说明（硬要求，不是可选项）

页面必须显式写清以下四条，**不允许静默缺失**：

- [ ] 依赖边**只统计同一链路段内**的调用。
- [ ] **异步调用的出口依赖不进图**（附原因：跨段配对需父段索引，父段可能已被淘汰 → 缺边无法与「没有这个调用」区分）。
- [ ] 依赖节点**只到组件类型**，不区分具体实例地址。
- [ ] 健康标记口径是**调用错误率**，**不是规则引擎告警**；分位是**抽样**得出的。

### 不做

- [ ] 不改既有链路可视化页、既有指标页及其口径。
- [ ] 不做前端单测（本仓无 JS 测试基建，不为此新建）；由 issue 05 断言「页面可访问 + 读口含新字段」。
- [ ] 不做导出图片 / 打印 / 分享等独立通路。
- [ ] 不为总览档做独立的「汇报模式」。
- [ ] 不改组件库映射（复用既有）。

## Comments

> 给领导看的那一档是**总览档**，不是明细档的简化版——它是一等公民视图，布局稳定性与节点命名可读性优先。
> 已知预期：演示环境依赖面很薄，总览档可能只有 2~3 个依赖点。**这是预期的**，机制正确性优先于图的丰富度。
