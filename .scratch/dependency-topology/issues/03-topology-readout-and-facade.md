# 03 — 依赖拓扑读口 + 宿主工具类接入

**What to build:** 新增一个**只读读口**暴露依赖边与依赖节点，并在宿主工具类（桩类 + 拦截器）各加一个方法打通。**左列入口端点不来自本读口**——由现有 Trace 指标读口提供，零改动。

**Blocked by:** 02.

**Status:** ready-for-agent

### 读口

- [ ] 新增只读读口，路径与形态与现有指标读口一致（`/inner/sw/...` 家族）。
- [ ] 参数：时间桶范围、分辨率、视图档位（总览档 / 明细档）。**不新增健康度阈值参数**（阈值是硬编码常量）。
- [ ] 响应含：节点列表、边列表、计数（含**溢出计数**）。
- [ ] 边的每条记录四字段齐全：调用量、错误数、耗时分位、最大耗时。
- [ ] **组件名解析留在宿主侧**：插件侧只透出**组件标识整数**；宿主用**已有的组件库映射**翻译成组件名（该映射与其加载/注入逻辑已存在，**直接复用**）。**Agent 侧不打包组件库**。
- [ ] 字段为**追加**语义、契约向后兼容；现有读口零改动。

### 接线

- [ ] 宿主工具类（编译期桩类）与运行期拦截器**各加一个方法**（与「从内存热层读视图」那对方法的既有先例同款）。
- [ ] 演示应用控制器加一个映射方法，暴露上述读口。
- [ ] 读取路径复用现有指标聚合器的加锁与快照读风格，**不引入新的并发模型**。

### 不做

- [ ] 不改任何现有读口的路径、参数或响应结构。
- [ ] 不做写入方向的新读口（无开关、无清空）。
- [ ] 不做导出/下载。
- [ ] 不加新的配置项。

## Comments

> 成本受控的关键点：**左列零新代码**。入口端点与端点级指标已有现成读口，页面直接取用——本票新增的只有右列（边）。
> 先例：桩类 + 拦截器各加一方法的模式，在「持久层为真相 / 内存热层为参照」那对读口上已有先例，照它对齐。
