## 完成情况

全部验收项已落地。断言组 E 共 20 条，其中 **5 条「不回归」**（Trace 指标读口 / `worstP*`+`bucketCount` / 极端值 / 告警 / 影子对账）——它们比任何新断言都重要，证明本 feature 确实没碰现有聚合与告警路径。

两点实现备注：

- **一处断言写错过并已修正**：首版断言 `p50 <= p90 <= p95 <= p99 <= maxLatency` 在**所有边样本都 < 20** 时必然失败——样本不足时 `p90/p95/p99` **合法地为 `-1`**（"样本不够"的口径，不是错误），拿它比大小是错的断言。改为：造数打到 25 轮让至少一条边越过 20 样本门槛，再**只对尾巴已产出的边**断单调性，并补一条"样本不足时为 -1"的正向断言。**没有**把断言弱化成恒真式。
- **有界性复核**：实跑 80 样本/边，存活边数 6、`edgeOverflow=0`、存活桶数 1–2，与 spec 的算术一致。

术语已写入 `CONTEXT.md`（依赖边 / 依赖拓扑 / 依赖边有界，各带 `_Avoid_` 同义词）；两个取舍的记录见 `docs/notes/2026-09-30-edge-aggregator-tradeoffs.md`。
