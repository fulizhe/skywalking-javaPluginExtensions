这个开关改写了哪些采集字段
采集项对应配置键被改写的字段
SpringMVC 参数plugin.springmvc.collect_http_paramsSpringMVCPluginConfig$Plugin$SpringMVC#COLLECT_HTTP_PARAMS
SpringMVC HTTP 头plugin.springmvc.include_http_headersSpringMVCPluginConfig$Plugin$Http#INCLUDE_HTTP_HEADERS（List；enable 恢复名单、disable 置空）
Tomcat 7/8 参数plugin.tomcat.collect_http_paramstomcat78x.TomcatPluginConfig$Plugin$Tomcat#COLLECT_HTTP_PARAMS
Tomcat 10/11 参数plugin.tomcat.collect_http_paramstomcat10x.TomcatPluginConfig$Plugin$Tomcat#COLLECT_HTTP_PARAMS
HttpClient 参数plugin.httpclient.collect_http_paramsHttpClientPluginConfig$Plugin$HttpClient#COLLECT_HTTP_PARAMS
Feign 请求体plugin.feign.collect_request_bodyFeignPluginConfig$Plugin$Feign#COLLECT_REQUEST_BODY
Dubbo 消费者入参plugin.dubbo.collect_consumer_argumentsDubboPluginConfig$Plugin$Dubbo#COLLECT_CONSUMER_ARGUMENTS（2.7.x / 3.x）
Dubbo 提供者入参plugin.dubbo.collect_provider_argumentsDubboPluginConfig$Plugin$Dubbo#COLLECT_PROVIDER_ARGUMENTS（2.7.x / 3.x）
JDBC SQL 参数plugin.jdbc.trace_sql_parametersJDBCPluginConfig$Plugin$JDBC#TRACE_SQL_PARAMETERS

缺失的插件（例如本 demo 没装 feign/dubbo）会被安全跳过，只告警不中断 —— 见 agent 日志的 "not found, skipped"。 截断阈值（SQL 512 / HTTP 1024 等）本开关**不调整**，故超长参数仍会被截断。
