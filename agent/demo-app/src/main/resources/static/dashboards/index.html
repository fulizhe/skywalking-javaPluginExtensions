demo-app 数据流仪表盘

logfile-reporter-plugin 六类数据流(链路段 / JVM / meter / 实例属性 / 告警 / profile)的本地内存报告可视化。 页面轮询与验证回路(scripts/validate.ps1)同一批 JSON 契约,静态资源随应用打包,无外部网络依赖。

01
Trace 缓存统计
链路段按 traceId 合并的缓存表与 span 时间线,含运行时开关状态
02
JVM 指标
CPU / 堆内存 / 线程 折线图,GC、内存池与类加载明细
03
Meter 指标
micrometer 桥接的单值与直方图指标,支持按名称过滤
04
实例属性
心跳携带的应用/OS/环境属性键值表
05
Trace 告警
告警运行指标、规则命中计数与 webhook 收讫事件流
06
Profile 快照
线程采样触发与带方法栈的快照列表
运行方式:pwsh ./scripts/validate.ps1(一键验证)或 pwsh ./scripts/run-with-agent.ps1(手动模式,保持运行后浏览器打开本页)
