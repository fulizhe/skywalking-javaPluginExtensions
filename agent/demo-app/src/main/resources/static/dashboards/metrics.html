TIANSHU · OAPLESS OBSERVABILITY

把全链路与指标留在应用进程内 —— 不部署 OAP、不依赖外部后端，单应用即可跨重启回溯、审计与聚合。基于 Trace 的指标面：请求数、错误率、慢调用与 P50–P99 分位数。

枢「天枢」＝北斗第一星，群星所绕之枢轴 —— 观测以应用自身为枢，不假外求。
