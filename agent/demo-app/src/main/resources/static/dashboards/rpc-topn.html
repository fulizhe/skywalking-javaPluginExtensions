口径说明（看这张榜之前必读）

  • 只算本 JVM 的出站 RPC（spanLayer = RPCFramework：gRPC / Dubbo / …）； 入站不计——本进程当 RPC 服务端的处理已在指标大屏的 endpoint 里。
  • 进程累计（自启动以来），不跟时间窗走；纯内存、重启即失、不落库。
  • 孤段不计：无 active trace 的后台 / 保活 RPC（无 Entry 且无 ref 的段）不出现——别把"没出现"读成"没调用过"。
  • 计数全量精确、分位来自每方法样本池（蓄水池抽样）；样本不足 20 条时 P95/P99 显示为 -。
  • 点行弹出的证据是抽样（最慢 1 条 + 随机 4 条），不是全量；证据给的 traceId 可能已超出链路存储窗口，点进去可能是空。
