# 「错误/弯路」沉淀为避坑手册（reference/omo-pitfalls.md）

用户明确要求「走过的路都是有效的，尤其是错误」。把教学素材从纯"知识线"扩展到"错误线"——踩过的坑单独汇总成可复用避坑手册，与教程互补。

**Evidence**: 用户原话「走过的路都是有效的，尤其是错误」。本教学空间已积累 6 个真实坑（goal 钩子拦消息、通用教程 agent 名不符、`@` 三类、`@tools_list` 非全局、控制台中文乱码假象、配置改后需重启），全部经源码/日志实证，写入 `reference/omo-pitfalls.md`，附五步排查清单。

**Implications**: 后续教学不再只基于 MISSION/RESOURCES 找新素材，而且要优先把「用户实际踩的坑」沉淀进 `reference/omo-pitfalls.md`。教学空间的价值主张 = 知识线（教程/速查）+ 错误线（避坑手册）双轨。参考文档从 `omo-cheatsheet.html` 扩展到含 `matt-omo-collab.md`、`omo-pitfalls.md`。
