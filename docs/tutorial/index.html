线一 · SkyWalking test/ 精读 → 可移植的集成测试模式

主线。以 apache/skywalking-java/test 为案例研究，最终产出能带去别的 Java / Go 项目用的模式。含真跑环节（Docker）。

  • MISSION · 为什么学
    为什么学这门课

    目标不是学会用 SkyWalking 的测试框架，而是抽出它背后的可迁移模式。含成功标准与范围边界。

  • LESSONS · 第 1 课
    两个测试台，一条信条

    test/ 的全貌地图（test/plugin vs test/e2e）+ 「场景即测试」这条信条 + 精读一个 scenario 的两份契约。约 10 分钟，无需动手环境。

  • REFERENCE · 术语表
    术语表

    两部分：上游专有名词（不认得就看不懂源码）+ 可迁移模式词汇（带「在别处叫什么」对照栏）。

  • RESOURCES
    一手来源清单

    上游源码 permalink、本仓库对照面、以及同一模式在 Testcontainers / Pact / k6 等生态里的对应物。
