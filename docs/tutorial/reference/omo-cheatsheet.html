OhMyOpenCode 常用命令 · 打印友好 · 随查随用

一、三种用法（核心心法）

方式怎么写什么时候用
直接打字帮我修一下 X简单任务、单文件改动（90% 的情况）
ultraworkultrawork 做 Y 或 ulw 做 Y复杂任务但懒得解释，让它自己探索+干活
Prometheus→执行切 Prometheus → 描述 → /ulw-execute多步骤硬活，想先被工程师式追问再动手

二、最常用的命令

OpenCode CLI（命令行）

opencode                 # 启动界面
opencode /path/to/proj   # 在指定项目启动
opencode -c              # 继续上次会话
opencode run "提示词"    # 不打开界面，直接跑一句
opencode models          # 列出可用模型
opencode auth login      # 登录/配置提供商
opencode stats           # 看 token 用量
opencode upgrade         # 升级

界面内斜杠命令

命令作用
/new开新会话
/sessions列出/切换会话
/compact压缩当前会话（省 token）
/undo撤销上一条消息
/redo重做被撤的消息
/models看/切模型
/agent切换 agent（Sisyphus/Prometheus 等）
/init引导生成 AGENTS.md
/exit退出

小技巧

写法作用
@文件名引用文件，把它内容加进对话（如 @pom.xml）
@agent名召唤子 agent 去干活（@explore @oracle @librarian @general）
!命令跑 shell，如 !git status

@ 菜单里的三类东西（别以为都是文件）

类别例子作用
文件@docs/README.md把文件内容加进对话
Agent（子 agent）@explore @oracle @librarian @Metis召唤专门 agent 干活，另开子会话
MCP 工具/资源@tools_list查看外部工具可用清单

环境：opencode 桌面 GUI —— 与终端版同机制，切换 agent 用左下角下拉点选即可。

三、核心 Agent（谁干嘛用）

Agent角色
Sisyphus总调度大管家，默认主编排
Prometheus动手前先访谈你、写出方案
Atlas读 Prometheus 方案，分派干活
Hephaestus深度重构，只支持 GPT 系列
Oracle只读顾问，架构/疑难问题
Librarian查文档/开源代码
Explore快速扫代码库
Metis动手前分析缺什么、有没有坑
Momus无情评审你的方案/代码

四、本项目（skywalking）配置备忘

  • sisyphus_agent.disabled: true — Sisyphus 不自动接管主控，保住 matt-skills 工作流；要靠 ultrawork/ulw 手动触发
  • goal.enabled: false — 关闭 goal 钩子（避免 2000 字符上限拦消息）。改这个后要重启 opencode 才生效
  • 只有 opencode-go 一家 provider，agent/category 都硬绑到 opencode-go/*

五、报错排查

发送命令失败 / Unexpected server error — 大概率是工具/配置问题，不是你的代码 bug。 去翻 C:\Users\lqzkc\.local\share\opencode\log\opencode.log 找 ERROR 行。 （本教学 0001 那节就讲了这个真实案例。）
