# Docs 目录索引（docs index）

本仓库为单上下文（single-context）：一个 `CONTEXT.md` + `docs/adr/` 在仓库根。AGENTS.md 只保留指向性链接，实际内容按主题下沉到各子目录，每个子目录有自己的 `index.md` 渐进披露。

- **Agent 技能文档** —— 何时读：理解 domain / issue-tracker / triage 消费约定。→ `agents/index.md`
- **架构决策记录（ADR）** —— 何时读：改动 active 模块前，先读触及区域的 ADR。→ `adr/index.md`
- **开发笔记** —— 何时读：配置 / 排查 OpenCode 与 OMO 插件时。→ `notes/index.md`
- **架构评审产物（review）** —— 何时读：阅读评审快照 / 走评审流水线时。→ `review/index.md`
- **规格与流程（spec）** —— 何时读：对 logfile-reporter-plugin 跑 Matt Skill 流水线时。→ `spec/index.md`
- **Repo 约定** —— 何时读：动模块、看已知 TODO 前。→ `repo/index.md`

> 根文件：`CONTEXT.md`（领域词表，探索前必读）；本目录即 docs 总入口。
