# Agent 技能文档（agent skills）

Matt skills 读取仓库领域的消费约定与载体。AGENTS.md 指向本目录。

- **域文档消费约定** —— 何时读：探索代码前，先读 CONTEXT.md + docs/adr/，了解领域词表与 ADR 冲突。→ `domain.md`
- **写作规则与 demo-app 工作细则** —— 何时读：写或改面向人的文档（README / NOTES / spec / 页面）时看 §1；改 `docs/tutorial/` 下的教学页面时看 §2；改 demo-app 脚本、跑压测或排查中间件时看 §3。→ `working-rules.md`
- **Issue tracker（本地 markdown）** —— 何时读：spec / issue 存 `./scratch/<feature-slug>/`；"publish / fetch ticket"、"wayfinding 操作"时。→ `issue-tracker.md`
- **Triage 标签映射** —— 何时读：技能提到 triage 角色（needs-triage / needs-info / ready-for-agent / ready-for-human / wontfix）时。→ `triage-labels.md`
