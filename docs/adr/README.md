# Architecture Decision Records (ADR)

This directory stores architecture‑decision‑records for `agent/logfile‑reporter‑plugin`.
All archived modules are out‑of‑scope.

Naming convention:
`adr‑NN‑short‑title.md`

Examples:
- adr‑01‑jdk17‑migration.md
- adr‑02‑deep‑rulesengine‑refactor.md

Rules:
1. ADR are written **after implementation is settled**.
2. Do not edit old ADR; if decision changes, write new ADR and reference old one.
3. Matt‑skill tools will read this folder automatically.
